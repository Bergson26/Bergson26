### Projets phares

**[My-Home-SOC](https://github.com/Bergson26/My-home-SOC)** — SOC & détection
Lab Wazuh / OpenSearch. 347 tentatives SSH détectées et bloquées.
Règles de détection personnalisées, corrélation d'événements, Fail2ban.

**[VulnPy-Scanner](https://github.com/Bergson26/VulnPy-Scanner)** — Gestion des vulnérabilités
Scanner CLI Nmap × API NIST NVD. Automatise la reconnaissance réseau
et l'identification des CVE associés aux services exposés.

**[DevSecOps Pipeline — LogiStock](https://github.com/Bergson26/projet-logistock)** — DevSecOps
Pipeline GitHub Actions à 11 étapes : Gitleaks, Semgrep, Bandit, Trivy,
déploiement AWS. 23 vulnérabilités identifiées, 8 documentées et tracées.

**[RiskGuard](https://github.com/Bergson26/riskguard-ebios)** — GRC
Analyse de risques EBIOS RM avec heatmap des scénarios, développé
en Python / Streamlit. Appliqué en contexte réel (audit hôtel, 2026).
